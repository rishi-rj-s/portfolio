# Portfolio - Rishiraj Sajeev

Portfolio site for **Rishiraj Sajeev**, Full Stack Engineer and Angular Developer at Axolon. Built with **Angular 21**, **Tailwind CSS v4**, and static prerender for crawlable HTML.

## Tech Stack

- **Framework**: Angular 21 (SSR/prerender)
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Build**: Angular CLI
- **Deployment**: Vercel + GitHub (static output from `dist/rishiraj-portfolio/browser`)

- **Database**: PostgreSQL, MongoDB, Redis, Supabase
- **DevOps**: Docker, AWS (EC2/S3), CI/CD, Vercel
- **Realtime**: WebSockets, Redis Pub/Sub
- **Frontend**: Angular, React, Next.js, Tailwind CSS, TypeScript

## Development

### Prerequisites

- Node.js v20.19.0 or newer
- pnpm

### Install & run

```bash
git clone https://github.com/rishi-rj-s/portfolio.git
cd portfolio
pnpm install
pnpm start
# http://localhost:4200
```

### Production build

```bash
pnpm run build
# Static prerendered output: dist/rishiraj-portfolio/browser
```

Optional local SSR server:

```bash
pnpm run serve:ssr:rishiraj-portfolio
```
